# 镜头与动态视频修复

- 根据 video-shotcraft 的 spotlight-hero-card 配方及其实际demo，借鉴单主角、推进和真正停留，按用户要求不复刻装饰轮廓。没有宣称复刻全部剧场光影或精确卡拍。
- 移除focus装饰框及通用标题下划线，focus从无运动改为按focal_x/y推进、落定。页面镜头使用项目色板与实际标题/CTA，去掉固定DREWES品牌和行业文字；竖版和方版不再强行套横版页面坐标。
- video_budget=true是实际动态意图；DeepSeek方案校验要求至少一段视频，仍受最多两段、5秒、占比40%的现有预算约束。
- 已有静态方案在勾选后点击生成时先重新规划，方案确认后才提交付费素材；服务端也阻止静默交付纯静态方案。动态预算纳入成片复用比较。
- image_prompt描述首帧，新增可选video_prompt描述主体动作；旧方案仍能使用兼容提示。生成视频层不再被collage隐藏，音频驱动时长超过源视频时平缓放慢播放以避免退回静帧。

验证：114项Python回归测试通过；TypeScript、JS语法和镜头函数检查通过。真实DeepSeek生产调用返回一个5秒image/video=true镜头。使用FFmpeg技术测试片作为视频源，实际渲染8秒短片并完整解码；检查聚焦前后与视频前后帧均有变化，横版聚焦帧红像素0，横/竖版静帧已人工查看。未新提交万相付费视频任务，未直接部署Ubuntu；这些技术测试不等于广告审美或实际视频模型效果验收。

更新后既有MP4不会自动改变。重新规划生成才会加入新的视频素材；仅重渲旧方案可去掉装饰框，但不会凭空新增视频镜头。
