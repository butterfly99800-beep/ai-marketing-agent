# 实际宣传片测试与改进（2026-10-25）

主题：虚构“拾色文具”，仅作演示。使用项目生产流程实际调用DeepSeek规划、百炼云端固定Ethan音色、万相生成3张图片和1段5秒主体动作视频。既有本地模型未用于配音。图片/视频任务记录保留，后续重剪未重复提交素材。

首版问题（从编码成片和原始动态素材抽帧确认）：
- 旁白驱动时间轴把计划5秒的动态镜头压成61帧（约2秒），手拿笔、落笔动作没来得及完成。
- 开场被压到不到2秒；多处中段大标题与整句字幕争抢画面。
- “几笔颜色，让今天有了新的位置”语义空泛；逐镜标题强化PPT读感。
- 品牌镜头走workflow分支，成为按钮列表；改分支后仍有装饰红线、多卡背景。

采用的video-shotcraft方法：单主角、按主体取景、推进后落定、完整动作弧、品牌记忆点留白；参考spotlight-hero-card的意图与实际示例，不套用剧场皮肤，不宣称全部特效或精确鼓点复刻。保留用户偏好的轻快镜头节奏，真实动作优先完整展示。

代码改进：
- 按句子真实音频对齐，但给开场3秒、视频5秒、普通镜头2秒、品牌1秒的最低展示时间。用额外静音补足，不裁旁白、不加速；完整自然语音超长仍按现有60秒上限拒绝。长旁白可能使实际片长超过参考时长。
- 新增可选show_title；中段自然画面可关闭大标题，品牌保留标题。竖版编辑版标题上移，字幕按短语显示，防止长句占满画面。短语内部时机按文本长度估算，句子边界来自实际音频，不宣称逐字强制对齐。
- 品牌优先于workflow，去掉装饰线和多卡拼贴，只保留单一主体、品牌与CTA。
- 动态片段满画面展示，已有自然动作不再叠加假推拉；无大标题时不统一加暗色遮罩。
- 上述反馈已写回导演提示词。演示成片的最终文字和镜头安排做了人工编辑，不代表模型未经编辑即可稳定生成同等质量。

素材与结构：3张新图，1段5秒万相视频，其余复用不同景别；同一云端音色；Wallpaper真实作曲配乐，按曲库CC BY要求随交付附署名。

验证：115项Python回归测试、TypeScript检查、字幕/镜头函数检查通过。最终片完整解码、音频峰值和关键帧采用项目quality检查；原始万相视频中可见拿笔与落笔的动作，已检查前/中/后帧。最终交付文件及技术指标以输出目录中的实测记录为准。尚未直接更新Ubuntu网站。
