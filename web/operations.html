连接说明

  1. 请在常用 Chrome / Edge 浏览器打开本工作台，避免内嵌浏览器被 Google 拒绝登录。
  2. 点击绑定，在 Google 页面选择账号并授予上传、频道只读和数据分析权限。
  3. 首次测试前，在 Google Cloud 的 OAuth 测试用户中加入要绑定的 Google 账号，并启用 YouTube Data API v3、YouTube Analytics API。

面向外部客户上线前，需要部署 HTTPS、配置线上回调域名，并完成 Google OAuth 验证及所需的 YouTube API 合规审核。当前为本机工作台。
